# Cognitive Computing (UCS420) Assignments

This repository contains assignment implementations and laboratory exercises for Cognitive Computing (UCS420).

## Contents
- **Introductory_Python_Programming.ipynb**: Basic Python syntax and fundamentals.
- **Assignment2.ipynb**: Operations on Lists, Tuples, Sets, and Dictionaries.
- **Assignment3.ipynb**: Data analysis and visualization using Pandas and Matplotlib.
- **Assignment4.ipynb**: NumPy array creation, manipulation, and statistical operations.
- **Assignment5.ipynb**: NumPy matrix math and linear algebra.
- **Assignment6.ipynb**: Custom mathematical functions, distributions, and multi-plot layouts.
- **Assignment7.ipynb**: Sales and category trend analysis with time series.
- **Assignment8.ipynb**: Machine learning models and classification with Scikit-Learn.
- **Assignment9.ipynb**: Text processing and natural language basics.
- **Assignment10.ipynb**: NLP text representation and analysis.
- **Assignment11/**: Computer vision model building and evaluation with LandingLens.
- **Assignment12.ipynb**: Conversational agent and chatbot implementation using ChatterBot.
